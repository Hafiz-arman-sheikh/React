# React + Tailwind CSS Practice Project

A responsive sign-in screen built while learning **React** and **Tailwind CSS**. The interface uses a dark theme, email and password fields, and a gradient sign-in button.

## Tech Stack
- React 19
- Tailwind CSS 4
- Vite

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Hafiz-arman-sheikh/React.git
   ```
2. Open the project folder:
   ```bash
   cd React
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Create a production build:
   ```bash
   npm run build
   ```
